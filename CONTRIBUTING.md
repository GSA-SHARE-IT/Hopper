# How to Contribute

Thank you for considering a contribution to Hopper, an open source project of the U.S. government. If you're unsure about anything, ask in an issue, or open the pull request anyway.

Please read this file, the [LICENSE](LICENSE) and the [README](README.md) before you start.

## Getting Started

Hopper is in early development and has no code yet. Until the first package lands, the most useful contributions are issues: questions, requirements from your agency, and problems you see in the approach.

### Building dependencies

There are no dependencies to install yet. This section will list them when the first package lands.

### Building the Project

There is nothing to build yet. This section will describe the build when the first package lands.

### Workflow and Branching

1. Fork the repository, or create a branch if you have write access.
2. Make your change on a short-lived branch.
3. Open a pull request against `main`, and work with a maintainer to get it reviewed.

### Writing Issues

When you open an issue, include:

- what you expected to happen
- what happened instead
- the steps to reproduce it, if it's a bug

Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md), not in a public issue.
