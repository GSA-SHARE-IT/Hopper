# Security and Responsible Disclosure Policy

If you believe you have found a security vulnerability in Hopper, please tell us privately so we can fix it before it is disclosed.

**Please don't open a public issue for a security vulnerability.**

## Reporting a vulnerability in this repository

1. **Preferred: a private security advisory.** Open a report from this repository's **Security** tab with **Report a vulnerability**. The details stay private while we look into them.
2. **Email.** If you can't use a security advisory, email marko@ndstudio.gov with a subject that starts with `[SECURITY]`.

Include what you found, where it is (file, path or command), and how to reproduce it.

## Reporting a vulnerability in a GSA system

This policy covers this repository's own code and documentation. If your report concerns a GSA system or service, use the [GSA Vulnerability Disclosure Policy](https://www.gsa.gov/website-information/vulnerability-disclosure-policy) instead. It explains how to submit a report, what is in scope, and how to conduct security research on GSA systems.
