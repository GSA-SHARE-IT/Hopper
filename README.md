# Hopper

Hopper brings advanced managed agents to the whole federal government, without vendor lock-in.

## About the Project

Hopper is an open-source managed agent platform that any federal agency can deploy, configure and extend on infrastructure it controls. It is designed to run on more than one cloud, so an agency can adopt it without tying itself to a single vendor.

The project is in early development. The architecture and roadmap are being written, and there is no released code yet.

### Project Vision

Every federal agency can run advanced managed agents on infrastructure it controls, without being locked in to a single vendor.

### Project Mission

Build and maintain an open-source agent platform that agencies can deploy, configure and extend on their own terms, and that gets better as each agency contributes back.

### Software Bill of Materials (SBOM)

A Software Bill of Materials (SBOM) is a formal record containing the details and supply chain relationships of various components used in building software.

In the spirit of [Executive Order 14028 - Improving the Nation's Cyber Security](https://www.gsa.gov/technology/it-contract-vehicles-and-purchasing-programs/information-technology-category/it-security/executive-order-14028), an SBOM for this repository is provided here: https://github.com/GSA-SHARE-IT/Hopper/network/dependencies.

For more information and resources about SBOMs, visit: https://www.cisa.gov/sbom.
